# 人格提示词语义化 —— 让画像真正改变回复

> E2E-14 把链路打通了（答题→评分→落库→注入 prompt），但**语义层是弱**的：
> 注入的是 5 个形容词而不是行为规格，且分档覆盖率有定量缺陷（见 §2）。
> 本迭代解决"真的造成影响"。**验收口径**（按 2026-09-21 关账轮更新）：
> ① **客观特征差异**（确定性文本度量）= 同样一句问话，对立画像的两个用户在新对话里
> 得到的回复在字数 / 问句数 / 安抚词 / 追问推进词 等**可观察特征方向 5/5 类 × 3/3 条**全中；
> ② **"人能感知"层**——原计划由 LLM-as-judge 盲判证实，2026-09-21 用户决议暂搁
> （见账本 E2E-F-98），触发复跑条件已写入账本。
> ① 是本阶段最终验收证据；② 留给后续使用中触发。

## 1. 问题（E2E-14 复核，账本 E2E-F-95）

现状注入文本（抓包原文）：

```
用户人格画像（五因素量表，每维度 6-30 分，18 为中性）：开放性中（18/30），
尽责性中（18/30），外向性中（18/30），宜人性中（18/30），神经质中（18/30）。
请在回应风格上贴合该画像，但不要直接点破你在套用测评结果。
```

三个缺口：

| # | 缺口 | 后果 |
|---|------|------|
| 1 | **只给形容词，不给行为指令** —— 全文没有一句说明「开放性高该怎么说话」 | 模型自行脑补心理学，行为不可控、不可测 |
| 2 | **分档覆盖率的定量缺陷** —— 中档 `14~22` 占 9/25 区间；按 6 题 Likert 求和的正态近似（sd≈3.46）：单维度落中档 **80.6%**，5 维度全中档 **34.0%**，人均仅 **0.97** 条 | **1/3 用户拿到的 prompt 与无画像完全相同**，功能对他们是死的 |
| 3 | 无「不同画像 → 可感差异」的验收口径 | 测试点 #10 只能人工裁定，无法回归 |

## 2. 方案

### 2.1 设计原则：给"相处说明书"，不给"AI 的性格"

要达到"他懂我"，靠的是 **AI 的联系方式贴合用户的体验方式**，而不是让 AI 扮演某种性格。
后者是表演、容易崩（变成话痨/客服/说教），前者才产生"被理解感"。因此：

- **基底人设不变**（温柔、共情、2-3 句、不评判）—— 画像**只调整"怎么说话"**
- 指令写成**可观察的输出特征**，不写抽象形容词
- 显式护栏：不点破来源、不给用户贴标签、调整"有感但不过火"

### 2.2 双通道分档（解决缺口 2）

| 通道 | 触发 | 措辞 |
|------|------|------|
| **绝对档** | 维度分 ≥23 或 ≤13 | 「外向性**明显偏高**：…」 |
| **个体内相对档（ipsative）** | 无绝对极端时，取**最高/最低**维度，且极差 ≥4 | 「外向性**在五项中相对最高**：…」 |
| 退化 | 极差 <4（真正平坦，如全选 3 → 全 18） | 返回空 → 回落基础人设（**不编造**） |

个体内比较是人格测评的标准做法（同一量表内各维度互比），且把覆盖率从 66% 提到近乎 100%。

### 2.3 五维度 → 行为规格（解决缺口 1）

| 维度 | 高 | 低 |
|------|----|----|
| 开放性 | 可用隐喻/抽象角度，允许留白；不必事事给操作步骤 | 直白说事、少比喻，落在他能做的事上 |
| 尽责性 | 回应可有条理（先…再…），认可他的努力与标准 | 放松不施压，不给"按步骤做"的任务感/清单 |
| 外向性 | 更主动、节奏轻快，多给互动感，可主动开话题 | 给足空间，不连珠炮追问、不催他多说；短回应是被允许的 |
| 宜人性 | 先认可再表达，语气温和，避免直接下判断/反驳 | 直接给判断和实话，少堆叠客套与附和（铺垫会觉得假） |
| 神经质 | 先稳情绪再谈内容；用确定措辞，少用"也许/可能"；不追问、不引入新担忧点、不轻描淡写 | 不必反复安抚，可直接谈内容，他受得住直接的话 |

> 措辞方向是「**用户的体验方式 → AI 该怎么说话**」，不是「AI 的性格」。这是本方案与
> "让 AI 扮演性格"的根本区别。

### 2.4 注入结构

```
① 基底人设（不变）
② 适配层  = 头部（含五维数字摘要）+ 逐条行为指令 + 护栏
```

## 3. 测试点

| # | 测试点 | 判定 | 验证方式 |
|---|--------|------|---------|
| 1 | 绝对极端维度产出对应指令，中档维度不出 | [A] | Go 单测：指令含/不含关键词 |
| 2 | 互斥性：高外向不得出现低外向的"不要连珠炮" | [A] | Go 单测：断言反向文案不存在 |
| 3 | 全中性（全 18）→ 返回空 → 回落基础人设（不编造） | [A] | Go 单测 |
| 4 | ipsative 回退：极差 ≥4 且无绝对极端 → 产出"相对最高/最低"两条 | [A] | Go 单测 |
| 5 | ipsative 不触发：极差 <4 → 返回空 | [A] | Go 单测 |
| 6 | 缺维度（只给部分）→ 按实际存在的工作，不补 0 | [A] | Go 单测 |
| 7 | 护栏三句齐全（不点破/不贴标签/不过火） | [A] | Go 单测 |
| 8 | 覆盖率：随机 10000 组 Likert 答卷 → 出指令比例 | [A] | Go 单测（统计断言，修前 66% → 修后应 ≥95%） |
| 9 | 注入文本进入 system prompt 且基底人设一字不改 | [A] | Go 单测（fake streamer 捕获 messages） |
| 10 | **两个对立画像的用户在各自新对话里得到可感不同的回复** | [A]+[V] | 端到端脚本：真实 LLM 生成 + 特征量化 + 截图/原文 |
| 11 | **盲判可区分**：去标识后独立 LLM 判定"哪段更适合内向·易焦虑的人" | [A] | 端到端脚本：判对率 ≥ 2/3（高于随机） |
| 12 | 基底共情质量未退化（画像不得把 AI 变成话痨/客服） | [M] | 人工裁定 + 脚本特征兜底（长度上限、安抚词仍在） |

## 3.1 实际结果（2026-09-21）

14/14 测试点 PASS（含覆盖率断言 66%→**95.5%**）；端到端取证：可观察特征方向 **5/5 类 × 3/3 条**、
去标识**盲判 6/6 判对**（随机基线 50%）。执行记录见 [personality-prompt-semantic-report.md](personality-prompt-semantic-report.md)
（含 §4.5 证据边界自述：样本小、判官与生成同源、只覆盖 2 个维度）。

## 4. 验收标准

- 测试点 1~9 全绿（纯逻辑，离线可跑）
- 测试点 10/11 的脚本证据入库（report + 原文对照）
- 测试点 12 人工裁定记录
- 覆盖率统计由 66% 提升到 ≥95%
- 门禁 0 FAIL + CI 全绿 + §2.5 收口

## 5. 边界（不做）

- 不引入向量/画像 embedding 检索
- 不做用户画像的时序演化（"最近变内向了"）
- 不改 proto（仍走 BFF 侧注入，见 ADR adr-2026-09-personality-prompt-injection）
- 不做多轮对话内的画像微调（画像只在会话开始时读取）

## 6. 已知风险

| 风险 | 应对 |
|------|------|
| 过度指令 → 模型变成夸张人格 | 护栏显式禁止；测试点 12 兜底（回复长度上限、安抚词仍在） |
| 画像差 → 回复差（把共情挤掉） | 基底人设作为不变层；A/B 检查共情要素是否保留 |
| ipsative 相对档被模型当成"绝对值" | 措辞明确写"在五项中相对最高"，不写"偏高" |
| 盲判测试本身不稳定（LLM 判官有噪声） | 多轮取多数；判定阈值定在 2/3 而非 100% |
