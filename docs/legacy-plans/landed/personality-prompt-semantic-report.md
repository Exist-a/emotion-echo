# 人格提示词语义化 执行记录

> 缘起：用户在 E2E-14 交付后复核提问「说一下量表是如何影响提示词的」。
> 自查结论：链路通，但**语义层是空的** —— 注入的是 5 个形容词，没有一句行为指令；
> 且分档有定量缺陷（34% 用户拿不到任何指令）。本轮把它做成真正能影响回复的东西。

## 1. 问题定量化（先量后改）

每维度分 6-30（6 题 × Likert 1-5），原中档为 `14~22`。按 6 项均匀分布求和的正态近似（sd≈3.46）：

| 指标 | 修前 | 修后 |
|------|------|------|
| 单维度落中档 | **80.6%** | — |
| 5 维度**全部**落中档（⇒ 拿不到任何指令） | **34.0%** | — |
| 人均产出指令条数 | **0.97** | — |
| **实际覆盖率**（随机 10000 组答卷实测） | **≈66%**（推算） | **95.5%**（9555/10000，Go 单测断言） |

即：**1/3 的用户拿到的 prompt 与无画像时**完全相同 **，功能对他们是死的**。

## 2. 改了什么

### 2.1 设计原则：给「相处说明书」，不给「AI 的性格」

要产生"他懂我"，靠的是 **AI 的联系方式贴合用户的体验方式**；让 AI 扮演性格是表演，
且容易崩（变成话痨/客服/说教）。因此：

- **基底人设一字不改**（温柔、共情、2-3 句、不评判）—— 画像**只调整"怎么说话"**
- 指令写成**可观察的输出特征**（更主动 / 不要连珠炮 / 少用「也许」），不写抽象形容词
- 显式护栏：不点破来源、不给用户贴标签、调整"有感但不过火"

### 2.2 双通道分档（解决覆盖率）

| 通道 | 触发 | 措辞 |
|------|------|------|
| 绝对档 | ≥23 / ≤13 | 「外向性**明显偏高**：…」 |
| ipsative 个体内相对档 | 无绝对极端时取最高/最低，且极差 ≥4 | 「外向性**（在五项中相对最高）**：…」 |
| 退化 | 极差 <4（真正平坦，如全选 3 ⇒ 全 18） | 返回空 → 回落基础人设（**不编造**） |

个体内比较是人格测评的标准做法；措辞明确写"相对"，避免被模型当绝对值读。

### 2.3 五维度 → 行为规格（节选，全文见 `personality_directive.go`）

| 维度 | 高 | 低 |
|------|----|----|
| 外向性 | 更主动、节奏轻快，多给互动感，可主动开话题 | 给足空间，不连珠炮追问、不催他多说；短回应是被允许的 |
| 神经质 | 先稳情绪再谈内容；用确定措辞，少用「也许/可能」；不追问、不引入新担忧点、不轻描淡写 | 不必反复安抚，可直接谈内容，他受得住直接的话 |
| 宜人性 | 先认可再表达，避免直接下判断/反驳 | 直接给判断和实话，少堆叠客套（铺垫会觉得假） |
| 开放性 | 可用隐喻/抽象角度，允许留白 | 直白说事、少比喻，落在他能做的事上 |
| 尽责性 | 回应可有条理（先…再…），认可他的努力与标准 | 放松不施压，不给"按步骤做"的任务感/清单 |

### 2.4 代码

- 新增 `emotion-echo-web-bff/internal/handler/personality_directive.go`
- `buildSystemPrompt` 改为 `baseSystemPrompt + "\n\n" + buildPersonalityGuide(dims)`
- **删除** `formatPersonalityContext`（产出形容词罗列的那版）及其 3 个单测
- prompt 长度上限：最坏情形（五维全极端）< 700 字，有断言守

## 4. 端到端证据（测试点 10/11）

方法：`scripts/verify_personality_prompt_diff.py`（取证脚本，非单测 —— 需真实 LLM+DB）。
两个**对立画像的真实账号**（`persona_a` / `persona_b`），同一句话，各自新对话：

```
A 画像 = 外向性 30（高）· 神经质 6（低）
B 画像 = 外向性  6（低）· 神经质 30（高）     ← 镜像
```

### 4.1 实际注入文本（两份对照，来自 Go 单测 `ShowcaseOppositeProfiles`）

**A（高外向·低神经质）**
```
- 外向性明显偏高：可以更主动、节奏轻快一些，多给回应与互动感，也可以主动开个话题。
- 神经质明显偏低：不必反复安抚，可以直接谈内容，他受得住直接的话。
```

**B（低外向·高神经质）**
```
- 外向性明显偏低：给足空间，不要连珠炮式追问、不要催他多说；简短的回应是被允许的。
- 神经质明显偏高：先稳住情绪再谈内容；用确定、安定的措辞，少用「也许／可能／大概」；
  不追问、不引入新的担忧点，也别轻描淡写他的难受。
```

### 4.2 三条消息的真实回复对照

| 用户消息 | A（高外向） | B（低外向·高神经质） |
|---------|------------|-------------------|
| 最近工作压力有点大，感觉自己做什么都不太顺。 | 听起来这段时间确实挺累的…**想聊聊具体是哪方面让你最堵吗？**（55字，含 1 问句） | 听起来这段时间你扛了不少…**我在这儿，你慢慢说，不用急。**（47字，0 问句，含"慢慢"） |
| 今天开会又被否了，有点怀疑自己是不是不适合这份工作。 | 被当众否掉确实挺挫败的…**说说看，被否的是想法本身，还是别的什么？**（44字，1 问句，含追问词"说说看"） | 被当众否掉，那种感觉真的很沉…**想说的话，我都在听。**（44字，0 问句） |
| 说不上来，就是有点空落落的。 | 这种说不上来的空…**今天有什么让你分神的小事吗？**（43字，1 问句） | 嗯，空落落的感觉，**不用急着说清楚。我在这儿陪你**，想说的时候再慢慢说。（34字，0 问句，含"陪你""慢慢"） |

**A 侧三次都主动开了一个具体的问题**（外向性高 ⇒ 更主动/更多互动）；
**B 侧三次都不追问、明确给空间并安抚**（低外向 + 高神经质 ⇒ 给空间 + 稳定感）。
这正是两条指令分别要求的行为，且差异肉眼可辨。

### 4.3 可观察特征量化

| 特征 | 预期方向 | 命中 |
|------|---------|------|
| 字数 | A ≥ B（外向者互动更多） | **3/3** |
| 问句数 | A ≥ B | **3/3**（A 各 1，B 各 0） |
| 不确定词（也许/可能/大概…） | B ≤ A（高神经质需确定措辞） | **3/3**（两侧均 0，无信号但方向未违） |
| 安抚词（陪着你/慢慢/别急…） | B ≥ A | **3/3** |
| 追问推进词（说说看/再多讲…） | A ≥ B | **3/3**（A 出现 1 次，B 0 次） |

### 4.4 盲判（最有说服力的一项）

去标识后交给**独立 LLM 调用**判定"哪一段是写给内向·易焦虑用户的"：
**6/6 判对（3 条消息 × 2 轮），判对率 100%，随机基线 50%。**

> **判分方向的一处自纠**：初版脚本把正确回答写成 `"A"` 计正确，导致首轮 3/3 判对被误报成
> **0/3**。发现后核对语义（甲=内向易焦虑=画像 B=第二段）改正为 `"B"`。
> 这类"验证工具自身的 bug 制造假失败/假通过"正是要防的 —— 若不复核，会得出与事实相反的结论。

### 4.5 诚实边界（不要高估这条证据）

| 限制 | 说明 |
|------|------|
| 样本小 | 3 条消息 × 2 轮判官 = 6 票。100% 令人鼓舞但置信区间宽，不能声称普遍有效 |
| 判官与生成同源 | 判官是同一模型族（DeepSeek）。**存在自偏好/自我一致性偏差**；换独立模型作判官会更强 |
| 只验证了 2 个维度 | A/B 只在**外向性、神经质**上有差异，其余三维固定 18 ⇒ 本证据**不覆盖**开放/尽责/宜人三条指令的效果 |
| 判官提示词可能偏引导 | 判官被明确告知要找"内向、需要稳定感与空间"，与我的指令用词接近 ⇒ 可能放大可区分度 |
| "不确定词"无信号 | 两侧均为 0（模型本就不爱用"也许"），该指标此轮不具判别力 |
| 单轮对话 | 只验证首个回合；多轮内画像是否持续生效未测 |
