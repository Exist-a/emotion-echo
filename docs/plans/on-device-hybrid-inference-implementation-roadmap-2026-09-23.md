### A.3 v1.0 是什么（v0.3 首次明确）

- **v1.0 状态** = 代码测试通过 + ready to deploy + 代码封版（feature freeze）
- **v1.0 部署** = 产品决定时点（今天/下周/1 月后/暂不部署皆可）
- **v1.0 之后** = v1.0 状态达到后即可开始端侧化（不等部署）
- **端侧化开发期间** = 独立分支/特性开关内做，**线上代码仍是 v1.0**
- **端侧化整套完成后** = 才进入下一发布版（v1.1 / v2.0，按产品路线图）

**结论**：端侧化是 v1.0 之后的独立大版本工作，不属 v1.0 范畴。

v1.0 封版 ──> (准备期 ∥ 阶段一) ──> 阶段二 ──> 阶段三 ──> 阶段四
