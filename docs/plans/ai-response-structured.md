# AI 回复结构化 & Markdown 支持 - 规划文档

## 📋 概述

### 问题
- AI 回复是纯文本，一大段没条理
- 不支持 Markdown（代码块、列表、加粗等）
- 不同类型问题需要不同回复风格

### 目标
1. 根据意图类型，AI 用不同的格式回复
2. 添加 Markdown 渲染支持
3. 保持情感疏导的自然对话风格

---

## 🎨 意图回复风格定义

| 意图类型 | 回复风格 | Markdown 支持 |
|----------|----------|----------------|
| `emotional_support` | 自然对话、共情、像朋友聊天 | ✅ 基础格式（换行、简单加粗） |
| `study_help` | 有条理、分步骤、温和鼓励 | ✅ 序号列表、加粗、分段 |
| `tech_help` | 清晰、有代码块、分步说明 | ✅ 代码块、有序/无序列表 |
| `career_help` | 结构化、有建议、有序号 | ✅ 列表、加粗 |
| `lifestyle` | 轻松、有帮助、小建议 | ✅ 简单格式 |
| `other` | 简洁、直接回答 | ✅ 基础格式 |

---

## 🔧 实现方案

### 阶段 1：前端添加 Markdown 渲染（先做！）
**优先级：P0**

1. 安装依赖
   - 新增 `marked` 依赖（最流行的 Markdown 解析库）
   
2. 修改消息渲染
   - 在 `app/pages/chat/conversation/[id].vue` 中
   - 用 `computed` 把 content 从 Markdown 转成 HTML
   - 用 `v-dompurify-html` 渲染（项目已有！）

### 阶段 2：后端改进 Prompt 策略
**优先级：P1**

1. 修改 `internal/pkg/llm/chain.go`
   - 根据当前识别到的 intent 类型，添加不同的回复指令
   - 在 system prompt 里明确要求格式

**不同意图的具体 Prompt 指令：**

#### emotional_support
```
回复要求：
1. 像朋友一样自然对话，语气温暖共情
2. 不要用序号或列表，保持流畅自然
3. 适当使用换行分段
4. 体现理解和支持
```

#### study_help
```
回复要求：
1. 用清晰的步骤说明（1. 2. 3.）
2. 关键点可以加粗（**重点**）
3. 结尾可以加鼓励的话
4. 保持温和耐心
```

#### tech_help
```
回复要求：
1. 步骤清晰，用序号列出
2. 需要代码时，用代码块包裹（```）
3. 语言简洁专业
4. 适当使用无序列表
```

#### career_help
```
回复要求：
1. 分点给出建议（1. 2. 3.）
2. 逻辑清晰，条理分明
3. 关键建议加粗标注
```

#### lifestyle & other
```
回复要求：
1. 简洁直接
2. 适当用列表或分段
```

### 阶段 3：优化流式渲染（可选）
**优先级：P2**
- 现在是逐字发送，可以优化成逐词或逐句
- 提升体验，但不是必须
