能感觉到你现在心里那根弦绷得挺紧的——想到下周那一刻，身体先替你紧张起来了，心跳快、坐不住，这些都是真实的反应，不是你不够好。

我们慢慢来，先不急着"解决"它，试着这样陪自己走：

1. **先接住这份心跳，而不是和它对抗**
   心跳快，其实是身体在说"这件事对我很重要"。你可以试着把手放在胸口，轻轻跟自己说一句："我知道你在紧张，我在。"不用马上让它平静下来，允许它先在那儿。越是想压住它，往往越紧。

2. **把"面试"这个大块头，拆成你能握住的小块**
   你向来是个认真、想把事情做好的人，所以焦虑里可能藏着"我想准备得足够充分"。那就把它分成几件小事：**提前了解岗位和公司**、**准备3个能讲清楚的小故事（做过什么、怎么做的、结果如何）**、**想好一两个你想问对方的问题**。每完成一件，就轻轻打个勾——**你是在一点点把不确定变成确定**。

3. **给身体一个"预演"的机会**
   焦虑常常来自"没经历过"。你可以在面试前一两天，**对着镜子或找个人，把自我介绍完整说一遍**，哪怕说得磕巴也没关系。说过了，那一步就不再是陌生的。面试当天提前到、深呼吸几次，让身体先熟悉那个环境。

4. **留一点余地给自己**
   你不需要表现得完美，**面试是双向的交流，不是一场审判**。你也在看它适不适合你。这样想，肩膀会松一点。

其实你现在会紧张，恰恰说明你在乎、你认真——这不是缺点。你愿意的话，可以跟我说说，这场面试是什么岗位，或者你最担心的是哪一部分？我陪你一起理一理。

[user] runes=15 :: 是技术面，我最怕被问到项目细节

[ai] runes=766 句子数≈18
技术面怕被追问细节，这个紧张特别能理解——因为那像是别人拿着放大镜，照到你最想藏起来的地方。但换个角度看，**面试官问细节，往往不是想挑错，而是想看看你是怎么思考的**。这一点，可能比"答对"更重要。

我们可以这样准备：

1. **先把项目"讲成一个故事"，而不是背一堆点**
   挑你最熟的那一个项目，按这个顺序理一遍：**它要解决什么问题 → 你负责哪部分 → 关键的技术选择是什么 → 结果怎么样**。你是个有条理的人，这一步对你来说不难，难的是"讲得自然"，所以先写下来，再讲顺。

2. **针对每个技术选择，问自己一句"为什么"**
   面试官最爱追的，就是"你为什么用A不用B"。**提前想好每个关键决策背后的理由**——哪怕当时的理由是"团队原本就用这个"或者"时间紧，先选了个能跑通的"，也如实说。**真诚的解释，比硬撑的完美答案更让人信服。**

3. **准备一个"我卡住过"的细节**
   这一点很关键：**主动说出一个你当时没搞定、后来怎么解决的细节**。比如某个bug查了很久、某个方案上线后才发现问题。这类回答反而加分，因为它显示你会复盘、会成长。你本来就习惯反思，这恰好是你的优势。

4. **不会的地方，别硬编**
   如果真被问到忘了的细节，可以坦然说："这块当时不是我主要负责的，我记得大概是……如果让我现在做，我会先去确认XX。"**承认边界 + 给出思路**，比含糊其辞安全得多。

5. **提前自问自答，把最怕的问题先"见"一遍**
   把你最怕被问的三个问题写下来，自己先答一遍，哪怕答得磕巴。**怕的往往不是问题本身，而是"第一次面对它"**。见过了，它就没那么吓人了。

你愿意的话，可以挑一个项目，跟我说说它大概是做什么的——我陪你一起把"为什么"这条线捋出来。

[user] runes=18 :: 那你觉得我该怎么准备上面那两个问题？

好，我们把它们落地成**具体能动手做的事**。你不用一次全做完，分两三天慢慢来就好。

**先准备"项目故事"（对应第1条）**

拿一张纸，只写四行，每行一两句话：

- **问题**：这个项目当时要解决什么？（一句话，别写术语堆砌）
- **我的部分**：我具体负责哪块？（说清"我做了"，不是"我们做了"）
- **关键选择**：我做了什么技术决定？（挑1-2个你印象最深的）
- **结果**：最后怎么样？（有数字最好，没有就说"上线了/稳定跑了多久"）

写完，**合上纸，用嘴讲一遍**，讲不顺的地方再回去补。讲三遍，基本就稳了。

**再准备"为什么"（对应第2条）**

把你刚写的"关键选择"挑出来，每个问自己三句：

1. 当时**为什么选它**？（性能、时间、团队习惯……真实就行）
2. **有没有考虑过别的方案**？为什么没选？
3. 如果**现在重做**，我会不会改？为什么？

第3句是加分项，能自然带出你的成长。答不上来的，就如实说"当时没想那么深，现在回头看……"

**最后，准备那个"卡住过"的细节（对应第3条）**

想一件**你当时真的被难住、后来解决或绕过去的事**。按这个顺序讲：

> 遇到什么 → 我先怎么试的 → 卡在哪 → 后来怎么破的 → 学到了什么

不用是惊天动地的大事，**越真实越好**。
