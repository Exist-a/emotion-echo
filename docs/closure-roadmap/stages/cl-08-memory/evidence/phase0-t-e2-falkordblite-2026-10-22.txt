做法：`FalkorDriver(falkor_db=<falkordblite 同步实例>)`，指望直接复用客户端。
结果：`TypeError: object QueryResult can't be used in 'await' expression`
原因：graphiti 的 FalkorDriver 走**异步**客户端（`falkordb.asyncio.FalkorDB`），
      falkordblite 暴露的 `redis.falkordb_client.FalkorDB` 是**同步**的。
⇒ 结论：**不能传实例，必须走 host/port**（见 phase0-t-e2b）。
附：falkordblite 自身完全可用（0.41s 起服务、Cypher 写入 + 读回 `[['云舟','建筑师']]`、list_graphs=['spike']）；
    安装 `pip check` 干净（graphiti-core 0.31.2 / falkordblite 0.11.0 / redis 8.1.0 / falkordb client 1.8.0）。
