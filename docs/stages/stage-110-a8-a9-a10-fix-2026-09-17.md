## 二、根因诊断

### A8 真根因 — 多个架构债叠加

**Stage 109b Sprint 已知 race**（已被 Sprint 108 architecture test 钉住）：
1. `useConversationSender` onUnmounted → `cancelAIStream` 在 navigateTo 期间同步触发
2. `useAIStreamHandler` `streamCancelled.value` 残留污染下次调用
3. `messageStore.addMessage` / `sendMessage` 用 `.push()` 在 Nuxt 3 + Pinia + 跨组件实例场景下偶发不触发响应式

**IAB 实测 2026-09-17 日志确证**：
- POST /api/v1/conversations ✓
- POST /api/v1/conversations/:id/messages ✓（user 消息写入）
- POST /api/v1/ai/stream **缺席**（AI 流不发）
- DOM 只有 user article，dialog-ai 缺席

### A9 真根因 — flex 容器无 min-width:0
sidebar-header 内 fold-btn (30px) + title (flex:1) + new-btn (30px) 在 sidebar 250px 减 padding 226px 可用空间下，title 被挤窄 → fold-btn 与 title 间距不规则。

### A10 真根因 — voice-btn 优先级 + 父级 flex 挤压
voice-btn 缺 display/width/height + background fallback，父级 .composer-actions flex gap 8px 挤压按钮尺寸。
