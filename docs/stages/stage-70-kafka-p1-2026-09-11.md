#### 二、bug 根因（侦察发现）

```bash
$ docker logs emotion-echo-ai-svc | grep "consumer started"
# 27 分钟日志 0 行 → Kafka Consumer goroutine 永远没启动！
```

**根因链**：

1. compose env 注入 `KAFKA_ENABLED=true`（ai-svc 行383 + chat-svc / analytics-svc 类似）
2. ai-svc `config.Kafka.Enabled bool` struct 字段 yaml 缺省 → bool 零值 `false`
3. `config.SetDefaults()` 函数**显式不覆盖** bool 字段（注释："无法区分零值与显式 false"）
4. ai-svc `applyEnvOverrides()` **漏读 `KAFKA_ENABLED` env**（grep 确认无此分支）
5. → `c.Kafka.Enabled` 永远 false → `if c.Kafka.Enabled && len(brokers) > 0` 进 else → `var pub = NewInMemoryEventPublisher()` fallback → **Kafka Consumer goroutine 永远不启动**

**修复前 docker logs 实证**（修复前 ai-svc 27 分钟日志）：
```
{"msg":"ai-svc HTTP server listening on 0.0.0.0:8891"}
{"msg":"FusionWorker started (tick=5s)"}
{"msg":"tick fired (counter=N)"}    ← 后续全是 fusion worker
# 永远没有 [kafka] consumer started / DLQ publisher connected
```

**修复后 ai-svc 启动日志**（commit `c67f428` v0.1.5）：
```
{"msg":"DLQ publisher connected: topic=chat-events-dlq","module":"kafka","svc":"ai-svc"}
{"msg":"consumer started: brokers=[emotion-echo-kafka:9092] topics=[chat-events] groupID=ai-svc dlq=true maxRetries=3","module":"kafka","svc":"ai-svc"}
```

**chat-svc 修复前**：
```
{"msg":"[events] using DevEventPublisher (KAFKA_ENABLED=false, dev-only path)"}
# 永远没 [kafka] producer connected
```

**chat-svc 修复后**（v0.1.8）：
```
{"msg":"[kafka] producer connected, brokers=[emotion-echo-kafka:9092]"}
```
