# ADR-2026-09 端侧化来源告知 = 「本地完成」角标（a）

> **状态**：🟢 **accepted**（2026-09-28 用户拍板；Lane O 立 ADR）

## 一、决策

按 v0.2 §十二 决策 3 + v0.3 §B.1，端侧化来源告知选 **(a) 「本地完成」角标**。

| 路径 | 描述 | 拍板结果 |
|------|------|----------|
| **(a) 「本地完成」角标**（**当前**）| AI 回复气泡右上角 / 底部加角标（端侧"🛡️ 本地完成" / 云端"☁️ 云端回复" / 高危"📞 援助热线"），用户一眼能识别回复来源 | **🟢 接受** |
| (b) 纯无感降级 | 端云回复外观一致；用户不知道哪条来自哪边 | 备选 |

### 1.1 UI 实现建议

| 来源类型 | 角标文案 | 角标 icon | 优先级 |
|----------|----------|-----------|--------|
| 端侧推理完成 | "本地完成" | 🛡️ | 显示 |
| 云端回复 | "云端回复" | ☁️ | 显示（默认态，让用户知道这是云端）|
| 高危 × 离线 | "📞 援助热线"（强制弹援助热线，v0.2 §5.1 "高危×离线"兜底）| 📞 | 强制弹窗（不算来源告知）|

## 二、影响面

### 2.1 决策 3=(a) 直接影响

- **chat-svc 入库字段增加**：`reply_source` 字段（`local` / `cloud` / `hotline` 三态）
- **前端 AI 回复气泡组件增加角标 wrapper**（复用现有 `MessageBubble`）
- **隐私宣传口径**："本地完成" + "云端回复"双向披露（诚实）
- **不影响** §六.5 护栏代码兜底 + §6.1 强约束 prompt（既有契约不变）

### 2.2 决策 3=(a) 派生约束

| 派生 | 影响模块 |
|------|----------|
| **OC-08 端云共用同一 prompt 组装层**（v0.3 §E OC-08） | 角标实现需在 chat-svc 入库前加 `reply_source` 字段 |
| **OC-10 端云比例埋点**（v0.3 §E OC-10） | 决策 3=(a) ⇒ 埋点必有 source 字段；E2E-21 收口后接入 Grafana |
| **决策 1 联动**（D-26.1）| 决策 1=(a) ⇒ "本地完成"角标 = 卖点；决策 1=(b) ⇒ 角标无意义（无云端）|

### 2.3 决策 3=(b) 备选代价（如选此项）

- 隐私宣传口径减弱（"勾选"模式）
- 用户对"永不离设备"产生错误预期（端云实际都有）
- v0.2 §1.3 原则 2 "诚实"违背
- 无新增 `reply_source` 字段（埋点简化但埋点失真）

## 三、调研依据

### 3.1 大厂先例

| 产品 | 来源告知方式 | 用户可见性 |
|------|--------------|----------|
| **Apple Intelligence**（2024）| 转第三方有弹窗 + 端侧无标识 | 半显性 |
| **Google Gemini Nano**（Chrome）| 端侧任务有标识（"Nano" 角标）| 显性 |
| **Microsoft Copilot+PC**（Recall）| 本地/云端可切换 | 显性可切换 |

### 3.2 v0.2 §十二倾向

> **角标**（大厂先例 + 诚实）

### 3.3 v0.2 §1.3 原则 2

> **过程平滑无感、来源显性可见**（v0.1 "无感降级"修订）—— 心理学场景信任建立核心

### 3.4 风险评估矩阵

| 风险 | 路径 | 概率 | 应对 |
|------|------|------|------|
| 角标过强 → 用户质疑"为什么不全本地" | (a) | 中 | 隐私政策文案解释 + E2E-12 settings 开关 |
| 角标过弱 → 隐私卖点看不出 | (a) | 中 | A/B 用户反馈（10 人内测，决策 3 拍板后启动）|
| UI 改动量低估 | (a) | 低 | 复用现有 MessageBubble + 新增 wrapper |
| chat-svc `reply_source` 字段加错 → 报表失真 | (a) | 中 | OC-10 埋点 + 报表 SQL 校验 |

## 四、验收契约指针（v0.3 §E + §G.1）

| 契约 | 描述 |
|------|------|
| **OC-08** | 端云共用同一 prompt 组装层（vitest 端侧/云端同输入同输出；`reply_source` 字段在 prompt 组装时确定）|

- 视觉验证：移动端（小视口）+ 桌面端（宽视口）各跑一次
