## 一、决策

按 v0.2 §十二 决策 1 + v0.3 §B.1，端侧化隐私定位选 **(a) 推理本地 + 消息照常上传**（用户 2026-09-28 拍板）。

| 路径 | 描述 | 拍板结果 |
|------|------|----------|
| **(a) 推理本地 + 消息照常上传**（**当前**）| 端侧推理完成的事**永不上云**（prompt + 模型权重本地）；用户消息仍走 BFF→chat-svc 入库 + 上报（保留会话历史 / 报表 / 测评）| **🟢 接受** |
| (b) 真·数据不离设备（**未来排期**）| 用户消息不入库，不上报，不上报情绪事件；端侧推理 + 本地 Dexie 缓存 | ⏸️ **等排期**（工作量 6~8 周 + L2 双轨架构）|

### 1.1 两阶段切换路径

| 阶段 | 时间窗 | 决策 | 工程影响 |
|------|--------|------|----------|
| **前期**（当前） | 即日起 | (a) 推理本地 + 消息照常上传 | 零管道改动；端云分流只动 `useAIStreamHandler.sendAIStream` 单点 |
| **未来**（排期版本） | 排期未定 | 0 (b) 真·数据不离设备 | 报表 / 画像 / 历史回显需整套本地双轨；换设备失忆；测评离线不可用 |

## 二、影响面

### 2.1 决策 1=(a) 直接影响

- **零管道改动**：BFF / chat-svc / analytics-svc 全链路不变；端云分流只动 `useAIStreamHandler.sendAIStream` 单点（v0.2 §3.2 插入口证据）
- **隐私卖点显性可见**：与 §三 决策 3 角标配合 → "🛡️ 本地完成"卖点
- **离线工程量小**：v0.3 §E OC-02~OC-04 离线契约 = 仅 outbox 补发；不需要本地双轨数据库

### 2.2 决策 1=(a) 派生约束

| 派生 | 影响模块 |
|------|----------|
| **OC-03 AI 回复补传契约 clientMsgId 幂等**（v0.3 §E OC-03） | 决策 1=(a) **强依赖**——客户端携带完整离线回复 POST + 幂等 + 保序 |
| **OC-08 端云共用同一 prompt 组装层** | 决策 1=(a) ⇒ L1 摘要可直接走服务端下发 |
| **决策 5 联动**（D-26.5）| 决策 1=(a) ⇒ D-26.5 = (a) 随 D-26.1 联动 ⇒ 摘要服务端生成 + 下发 |
| **离线范围决策**（D-26.4）| 决策 1=(a) ⇒ L0+L1 应做（OC-05 必做）；L2 二期 |

### 2.3 决策 1=(b) 备选代价（如选此项）

- 报表 / 画像 / 历史回显需整套本地双轨（v0.2 §十二决策 1 影响列）
- 换设备失忆（除非同步加密镜像）
- 测评离线不可用
- 工作量评估：6~8 周（v0.3 §C.3 阶段二 L2 双轨架构）
- E2E-15 dashboard 同型改造（留账 §9 #2 已知）

## 三、调研依据

### 3.1 大厂先例

| 产品 | 端云分流策略 | 用户可见性 |
|------|--------------|----------|
| **Apple Intelligence**（2024）| 端侧 ~3B → PCC（私有云）→ 第三方 OpenAI | 显性：转第三方有弹窗 |
| **Google Gemini Nano**（Chrome 内置）| 端侧任务有标识（无云端兜底）| 显性标识 |
| **Microsoft Copilot+PC**（Recall 撤回事件）| **本地优先 + 云端可选**；Recall 因云端同步隐私争议撤回 | 显性：本地/云端可切换 |
| **Woebot / Wysa**（心理赛道）| **100% 云端**（无端侧先例） | 不适用 |

### 3.2 v0.2 §十二倾向

> **(a) 推理在端侧、消息照常上传**（管道零改动、离线工程量小、报表零感知）

### 3.3 风险评估矩阵

| 风险 | 路径 | 概率 | 应对 |
|------|------|------|------|
| 用户误以为"消息也本地" | (a) | 中 | §三 决策 3 角标（"本地完成"显性）+ 隐私政策文案 |
| 端云分流导致 L1 历史缺失 | (a) + 决策 4=L0-only | 低 | 决策 4 推荐 L0+L1（OC-05 覆盖）|
| 端侧泄露 prompt + 权重 | (a) | 极低 | 端侧推理完成的事不上云（强约束 = prompt + 模型权重本地）|
| 切换 (b) 后改回 (a) 工作量 | (a) → (b) → (a) | 低 | 决策 1=(a) 后 = "事后改 (b) 工作量大"；决策 1=(b) 后 = "改 (a) 几乎不需改代码"（双轨架构预留扩展点）|
