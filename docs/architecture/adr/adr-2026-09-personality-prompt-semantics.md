# ADR: 人格画像的提示词语义设计（相处说明书，非 AI 性格）

## 上下文

E2E-14 打通了「人格量表 → 评分 → 落库 → 注入 system prompt」的链路（ADR
[adr-2026-09-personality-prompt-injection](adr-2026-09-personality-prompt-injection.md)），
但复核发现**语义层是空的**（账本 E2E-F-95）：

| 缺口 | 实测 |
|------|------|
| 注入内容是「形容词罗列」（`开放性中（18/30），…`），全文没有一句说明「开放性高该怎么说话」 | 模型只能自行脑补心理学，行为不可控、不可测 |
| 分档覆盖率的定量缺陷：中档 `14~22` 占 9/25 区间 | 单维度落中档 **80.6%**、5 维全中档 **34.0%** ⇒ **1/3 用户拿到的 prompt 与无画像完全相同** |

产品目标（用户原话）：「同样的新对话里，不同量表结果的人返回不同感觉的回答，
让用户感受到**他是懂我的**」。这个目标决定了两条互斥的实现路线，必须先选。

## 决策

### 决策 1：给「如何与这个人相处」的说明书，**不是**给「AI 的性格」

| 路线 | 做法 | 为何不选 / 选 |
|------|------|--------------|
| A. AI 扮演性格 | 告诉模型"你是一个外向的、情绪稳定的人" | ❌ 这是**表演**：容易崩（变成话痨/客服/说教），且"AI 有自己的性格"与用户无关 —— 用户要的是**自己被理解**，不是对方有个性 |
| **B. 相处说明书（采纳）** | 描述「**该维度的用户**需要 AI 怎么说话」 | ✅ "被懂"来自 **AI 的联系方式贴合用户的体验方式** |

**落地约束**：基底人设（温柔、共情、2-3 句、不评判）**一字不改**；画像只调整"怎么说话"。

### 决策 2：指令必须是**可观察的输出特征**，不是形容词

写「更主动、节奏轻快，可主动开个话题」而不是「外向性高」。
理由：形容词要求模型自行映射到行为，不可控；可观察特征可直接验收（问句数、字数、安抚词）。

### 决策 3：双通道分档（绝对档 + ipsative 个体内相对档）

| 通道 | 触发 | 措辞 |
|------|------|------|
| 绝对档 | ≥23 或 ≤13 | 「外向性**明显偏高**：…」 |
| **ipsative 相对档** | 无绝对极端时取最高/最低，极差 ≥4 | 「外向性**（在五项中相对最高）**：…」 |
| 退化 | 极差 <4（真正平坦，如全选 3 ⇒ 全 18） | 返回空 ⇒ 回落基础人设（**不编造**） |

依据：个体内比较是人格测评的标准做法（同一量表内各维度互比），且把覆盖率从 **66% 提到 95.5%**。
措辞必须写明"相对"，避免被模型当绝对值读。

### 决策 4：三句护栏进 prompt

1. 不点破来源（不说"根据你的测评/你的分数"）—— 被点破会显得临床、冒犯
2. 不给用户贴标签（不说"你是个内向的人"）—— 用感受贴合，不用标签定义
3. 调整要有感但不过火 —— 防退化成话痨/空话

## 后果

- **正面**：覆盖率 66% → 95.5%；差异可量化验收（特征方向 5/5 类、去标识盲判 6/6）；
  指令表是声明式的，可审计可调参；平坦画像正确回落（不编造）
- **负面**：prompt 变长（最坏情形 <700 字，有断言守），每次对话多带这些 token
- **负面**：**证据强度有限** —— 盲判仅 3 条消息 × 2 轮、判官与生成同源（同模型族，
  存在自偏好偏差）、A/B 只覆盖外向性/神经质两维 ⇒ 不覆盖开放/尽责/宜人三条指令
- **后续**：换独立模型作判官复验；扩到 5 维对立；测多轮对话内是否持续生效；
  若要产品化"感知"结论，需要真人评测而非 LLM 判官
